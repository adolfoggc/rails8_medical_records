# RAILS 8 Template

A quick template for RoR 8 Projects with Tailwind and Rails Blocks

## To Run
  Use ```bin/dev``` boot up the server with support to Tailwind

## Software Version
- Version 0.5

## Important Gem Versions
- Ruby 4.0.9
- Rails 8.1.4

## Updates in this version
- Dashboards controller
- Dashboard template
- Fix Accordion

## Configuration
Before starting the development of a new project, look for mentions of "rails8_template" in the project and change it accordingly to you new project to avoid conflicts in databases

## Tools
### Linting
Rails 8 already uses Rubocop. So you can check the linting using

```
rubocop
```
